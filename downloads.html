Install

  • Windows VST3: copy 3xOSO.vst3 to C:\Program Files\Common Files\VST3. CLAP: copy 3xOSO.clap to C:\Program Files\Common Files\CLAP.
  • Linux VST3: copy to ~/.vst3. CLAP: copy to ~/.clap. Run ./3xOSO for the standalone app.
  • Windows may warn about an unsigned app on first run. The builds are not code-signed yet.

What's new in v1.0

  • Chord mode (fun): one key plays a whole chord — major, minor, sus4, maj7, min7, power or octaves. In the web synth and the plugin.
  • Undo / redo (usable): step back through your last 60 sound edits with Ctrl+Z / Ctrl+Shift+Z in the web synth. The plugin keeps 8 built-in presets, a Surprise me button and full DAW automation.
  • Sound banks and MIDI export (commercial): export and import your whole library as one 3xoso-bank.json to share or sell preset packs, and export the step sequencer as a .mid file for any DAW.
  • Drift: analog-style slow pitch wander per voice in the plugin.
  • New look: the full Circuit Drift Labs identity, with a live output LED and a scrolling data stream in the plugin.
