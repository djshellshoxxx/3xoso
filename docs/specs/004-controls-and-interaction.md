# Controls and Interaction Specification

## Per oscillator

- On/off
- Shape selector
- Coarse tuning, -24..+24 semitones
- Fine tuning, -100..+100 cents
- Pan, -1..+1
- Stereo detune, -50..+50 cents per side with opposing signs
- Left phase offset, 0..360 degrees
- Right phase offset, 0..360 degrees
- Invert phase
- Mix level for Osc 2 and Osc 3 only

## Global

- Master level
- Phase Rand
- HQ
- AM OSC 3
- Learning Mode
- Panic

## Performance input

Pointer piano supports C4..C5. Computer keys `A W S E D F T G Y H U J K` map to the same notes. Multiple simultaneous keys may remain active for chords.

## Guided experiments

Experiment buttons replace the oscillator state with intentionally legible configurations. They do not start notes automatically and therefore never create audio without a user gesture.
