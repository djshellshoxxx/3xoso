# User Guide

- **Run:** open `index.html` in a browser, or use the GitHub Pages site (README "Running it").
- **Oscillators:** three oscillators with sine, triangle, square, saw, rounded saw and noise shapes, with tune, volume, pan, phase, invert, mute and solo.
- **Learn mode** explains each control with the maths at the current values. **Play mode** hides the explanations.
- **Lessons:** eight guided lessons (pure tone, harmonics, octaves and fifths, beating, phase cancellation, detune width, AM, noise).
- **Presets:** 46 presets, each with a demo pattern.
